## 🎯 快速开始

如果你是 Linux 新手，建议按以下顺序学习：

1. 🐧 先了解 Linux 文件系统结构（FHS）
2. ⌨️ 掌握 Bash 基础命令，能够熟练操作文件和目录
3. 🔑 理解用户、用户组与文件权限
4. 📦 学习使用包管理器安装与管理软件
5. 📝 编写 Shell 脚本实现日常自动化

## 💡 学习建议

- **多动手**：Linux 命令需要在终端反复练习才能记牢
- **善用 man**：遇到不熟悉的命令优先 `man <command>` 查看官方手册
- **善用 Tab**：补全命令与路径，能极大提高效率
- **做笔记**：把自己常用的命令和组合记下来，形成自己的 cheat sheet
- **拥抱终端**：尽量在终端完成日常操作，会越用越顺手
