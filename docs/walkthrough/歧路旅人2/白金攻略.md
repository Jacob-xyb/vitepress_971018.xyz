# 歧路旅人2白金攻略

## 开局

- 无论是哪个角色开局，首要任务是集齐所有角色

- 坚果理论上可以随便吃，有必过隐藏boss攻略，所以大致放心

## 角色特性

- 盗贼：白天偷东西（Lv越高成功率越高）、晚上战斗增益buff

- 学者：战斗自动调查；大后期爆炸输出 = 前期便秘

- 猎人：海鸣洞穴抓光兵 = 游戏速通（不推荐），猎人其实大后期才有用

- 医师： 潜力爆发，无消耗调和 = 无敌

- 学者： （潜力+学者）中期破盾手；

- 剑士： 武器大师，中庸中庸

- 舞娘： 跳跳舞图个乐

- 商人： 鸡肋，但是有钱=无敌；买船/大富豪刷级都靠他

## 白金

- 为了隐藏boss，剑士、学者等级一定要高

- 除了隐藏boss，没必要看攻略，就挺好玩的，速白会让这个游戏变的异常枯燥
