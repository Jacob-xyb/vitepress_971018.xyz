# 后期攻略

## 后期大富翁100倍exp刷级

《歧路旅人2》的“大富豪100倍经验”是一个能让你瞬间飞升的官方外挂式刷级法。简单说就是**雇佣特殊NPC“大富豪”**，利用他随机的**100倍经验/JP加成**，找高经验怪战斗，一次获得几十万经验直接升到80级以上。

具体操作分为三步：

### 📝 第一步：准备工作（解锁大富豪）
*   **通关商人主线**：必须完成商人帕特提欧的全部主线剧情。
*   **完成支线任务**：去**威尔格罗布**的豪宅找管家接任务。白天在**百货店旁**用学者打听情报，晚上在**左边杂货铺旁**再打听一次。
*   **雇佣大富豪**：回去交任务后即可雇佣，原价20万。用**学者调查**他可打折到**16万**。也可用**3个“章鱼烧”** 替代。
*   **带上关键角色**：队伍里必须有**神官**（为了80级后白嫖）和**商人**（召唤大富豪）。

### ⚔️ 第二步：刷100倍经验（核心操作）
*   **选好目标**：前往**梅林希尔斯**（光第二章的城市），出城找**异邦暗杀者**战斗。
*   **战前准备**：睡觉攒满潜力。建议给神官带**幸福胸针**或**EXP增幅器**等经验饰品。
*   **战斗与SL**：商人不断用“援助”召唤大富豪“跳舞”。他的效果随机（2/5/10/100倍）。如果没出100倍EXP，就**读档（SL）重来**。大富豪一次雇佣能用**3次**，每次援助会跳两次舞，所以一场战斗有**6次机会**。
*   **击败敌人**：一旦刷出100倍EXP，就用满BP召唤“老战士”等强力佣兵迅速结束战斗。击败暗杀者后，基础6600经验会被放大到**66万**。

### 💡 几个关键提醒
*   **善用SL**：这是核心，没刷到就果断读档。
*   **神官80级是关键**：神官升到80级后，可直接 **引导** 大富豪，实现无限次免费雇佣。
*   **战斗技巧**：异邦暗杀者物理攻击高，带上**盗贼**用“暗幕”技能可以大大提升生存率。
*   **注意平衡**：一次100倍经验足以让角色从40级直升60-70级，可能会让后续主线战斗变得过于简单，破坏挑战性，建议酌情使用。

这套方法可以让你在短时间内全员80级以上。祝你刷级顺利！
