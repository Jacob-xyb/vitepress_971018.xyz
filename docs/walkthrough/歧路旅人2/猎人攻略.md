# 猎人攻略

## 魔宠推荐

猎人的魔宠选择很丰富，不同阶段和玩法侧重会有不同的“最优解”。下面我按**开局、前期、功能、毕业**几个维度，为你整理了一些公认好用的魔宠。

### 🐣 开局魔宠选择：猫头鹰 vs. 狗

游戏开局时，猎人欧修缇需要在猫头鹰和狗之间做出选择。

*   **猫头鹰（推荐）**：属于魔法宠物，能针对敌人的元素弱点。猎人自身更擅长物理攻击，选择猫头鹰可以更好地实现**物理与魔法输出的互补**，在面对不同敌人时更灵活。
*   **狗**：属于物理宠物，能针对武器的物理弱点。虽然也很强，但功能和猎人本身的定位有些重合。

### 🚀 前期/过渡期强力魔宠

在游戏前期，可以优先考虑捕捉以下魔宠来降低开荒难度。

*   **古代遗物光兵**：这是前期非常强力的魔宠。可以前往**海鸣洞穴**（一个40多级的地图）捕捉。建议先将队伍练到20级以上，捕捉时需要消耗3点BP。
*   **大猫**：在高等级地图随机遇见，它的技能会随机给予我方4种增益Buff（物攻、属攻、速度、闪避等）中的一种。属于“摸奖”型宠物，遇到了可以顺手抓一只。

### 🛠️ 功能性魔宠推荐

这类宠物在特定战术或Boss战中能发挥奇效。

*   **历战之鲛(3BP)**：技能“完全营养捕食”能对敌方全体造成 **9999** 点固定伤害，并为我方全体**恢复HP、SP，且增加1点BP**。在海上击败Boss后有概率刷新出现。
*   **海坊主(3BP)**：技能“左直拳”能**一次击破6层护盾**，是打破高护盾敌人的利器。在海上东南部的大漩涡处击败Boss后，夜晚在海面上有概率遇到。
*   **噬梦(3BP)**：技能可对敌方全体进行暗属性攻击，并为我方全体**附加2回合的物理回避和魔法反射**效果。可以在东大陆克里斯特兰多地区的“无缘墓地”找到。
*   **布爾喬亞凱特林**：全区域随机出现的稀有魔宠。它的技能会随机触发**无敌、反射法术、全体复活**等强力效果，搭配猎人的EX技能“集体唆使”效果更佳。
*   **奥克托林王**：同样是全区域随机出现的稀有魔宠。它能在没有增幅的情况下**随机降低敌方全体的多项属性**，配合“集体唆使”能在一回合内大幅削弱敌人。

### 👑 毕业级输出魔宠

当游戏进入后期，恐狼是你绝对不容错过的顶级输出魔宠。

*   **恐狼(3BP)**：被誉为猎人最强的输出宠物之一。它的技能能对敌方全体造成**连续4次短剑伤害**，并**在8回合内降低敌方全体物防和速度**。在破防状态下，总伤害可高达 **35000** 左右。
    *   **捕捉地点**：东大陆温特兰多地区的“巨壁的地下洞（奈落之城）”。

### 💡 补充说明

*   **捕捉上限**：猎人最多可以携带10只魔宠，但其中有4个位置会被剧情相关的魔宠锁定，所以你实际可以自由配置的栏位是 **6个**。
*   **捕捉技巧**：将怪物HP削减至20%以下，或使其陷入**破防、异常状态**时，捕捉成功率会大幅提升。
*   **魔宠加工**：不需要的魔宠可以“加工”成消耗品，魔宠星级越高，加工出的道具效果越强。

### 💎 总结

总的来说，一个比较通用的毕业魔宠组合可以是：
*   **恐狼**：担当主力输出。
*   **历战之鲛** / **海坊主**：提供功能性（续航或破盾）。
*   **噬梦** / **布爾喬亞凱特林**：提供强力防御或增益Buff。

你可以根据自己的战斗风格和面对的敌人，灵活调整这6个栏位。
